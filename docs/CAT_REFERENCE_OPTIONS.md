# 灰猫／V4 白猫参考选择

本次增加两套可选猫咪参考，继续由项目和系列的 `canon_profile_id` 决定生产输入。目录不维护第二份“当前猫咪图片 ID”。已有作品的 Canon、任务和媒体引用保持原样。

## 用户入口

| 入口 | 行为 |
|---|---|
| 新建短片、新建系列 | 默认选中原版灰猫，提交时显式携带 Canon ID；也可选择 V4 校色白猫 |
| 导入的新系列／独立短片 | 每个故事组独立保存猫咪选择，随生产目标恢复；切换不会重新分析原文 |
| 导入到既有系列／短片 | 显示并继承目标绑定；显式传入冲突 Canon 时拒绝确认 |
| 尚未制作的独立草稿 | 可更换整套参考，重新查看生成预览 |
| 系列草稿 | 原子更新系列及未制作单集；单集不能单独换猫 |
| 已开始制作 | 提供“用其他猫咪重制”，创建独立的新作品 |

重制先展示名称、继承摘要和原始输入。确认只创建本地对象，不启动模型。系列入口创建新系列；单集或独立短片入口创建独立短片。

## 两套参考

声明清单位于 `assets/cat-reference-options.json`，只包含仓库相对路径、SHA-256 和已确认的身份文字。

| 选项 | 猫咪主图 | 人猫比例图 | 辅助资料 |
|---|---|---|---|
| `gray-original` 原版灰猫 | `assets/canon/v4/episode-cat.png` | 同目录 `pair-scale.png` | 当前正式主图、比例图 |
| `white-v4` V4 校色白猫 | `assets/character-previews/white-cat-v4-color-corrected/side-standing.png` | 同目录 `pair-scale.png` | 正面、背面、三视图 |

儿童和画风板共用 `assets/canon/v4/episode-child.png`、`style-board.png`。辅助图片只供页面查阅，不进入普通生成请求。视频基础参考顺序保持儿童、所选猫咪、同套比例、本集环境、画风板。

启动时优先复用图片哈希和身份文字一致的已有 Canon；缺失时创建 `activate=false` 的快照。已确认目录不会随全局默认发布自动重新绑定。缺失或哈希异常的文件显示不可用，不自动替换成另一只猫。历史其他 Canon 显示“历史参考设定”。

## 数据和事务

迁移：`0035_character_references`。

- `cat_reference_options` 保存稳定键、名称、Canon 外键、辅助图片和排序。
- 项目与系列新增 `production_started_at`，任务入队或保存结构化生产内容时锁定；历史记录回填。
- `character_remakes` 保存来源类型、来源 ID、目标 ID、目标 Canon、原始输入快照、请求哈希、幂等键和创建时间。
- 生产失败、取消或提交状态未知均不解除锁定。
- PostgreSQL 统一先锁系列，再按 ID 锁其项目；入队和切换使用同一所属对象锁。
- 生成请求首次读取的 Canon 保存在请求上下文，任务冻结时再次核对，入队事务再核对实际绑定。切换和生成并发只能一个成功。
- 重制以幂等键获取 PostgreSQL 事务级 advisory lock，先处理重放，再比对来源快照哈希并创建目标，避免重复创建。
- 清理逻辑保护目录的 Canon、主图、辅助图片和重制来源记录。

重制复制原始故事输入、用户补充消息、制作参数和来源文本绑定。生成的提案、分镜、环境、视频和连续性状态不复制。新提示词明确所选 Canon 决定外观，原文决定动作与因果，不做颜色字符串替换。

## HTTP 契约

| 接口 | 用途 |
|---|---|
| `GET /api/v1/canon/options` | 选择目录、图片、身份说明、可用状态 |
| `GET /api/v1/projects/{id}/reference-binding` | 独立／单集实际绑定和修改策略 |
| `GET /api/v1/story-series/{id}/reference-binding` | 系列实际绑定和修改策略 |
| `PATCH .../reference-binding` | `canonProfileId` + `expectedCanonProfileId` 的草稿切换 |
| `POST /api/v1/character-remakes/preview` | 来源、目标 Canon、可选标题，返回继承摘要与 `inputHash` |
| `POST /api/v1/character-remakes` | 增加 `expectedInputHash` 和 `idempotencyKey`，幂等创建 |

同值重复设置返回当前结果；制作锁定、绑定变化、单集越权、过期重制预览返回冲突。新建和导入 DTO 增加可选 `canonProfileId`；旧客户端省略时仍走原默认逻辑，无效的显式 ID 不回退。

导入确认快照升级为版本 2；版本 1 缺失的 `canonProfileId` 按 `null` 比较，重放使用原请求而非当前全局默认。
