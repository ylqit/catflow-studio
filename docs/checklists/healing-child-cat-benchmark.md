# 一人一猫治愈短片验收与竞品复现实验

## 黄金样片

`tests/golden_healing_child_cat_cases.json` 是版本化的十主题输入集。每次准备把组合包设为推荐入口时，使用 Canon-v2、平衡档和同一供应商配置逐条运行，并记录：

- 从一句话到故事候选的主动操作数；
- 每镜付费生成次数、等待时间和费用；
- 人物身份、猫咪身份、画风、身体结构、动作顺序、场景稳定性；
- 自然猫或轻拟人猫规则是否违规；
- 原生音轨、转场音频拼接和最终技术 QC；
- 人工审核、退回、覆盖理由和最终导出版本。

放行阈值：人物身份与画风抽样帧人工通过率不低于 90%；猫咪模式违规为 0；至少 8/10 主题在每镜不超过两次视频生成内可批准；最终资产技术 QC 与原生音轨通过率均为 100%。真实供应商结果不应写入单元测试快照。

## 外部视频工具对照

从黄金样片中固定选择五个主题，复用相同人物、猫咪和室内/户外参考包；每个平台每镜最多两次付费尝试。逐项记录总操作数、等待时间、实际费用、角色和画风稳定性、首尾帧或多图引用职责、问题定位能力、整镜重做与局部修复粒度。

对照实验只用于产品决策，不改变首版供应商边界，也不得以平台隐式记忆替代 Canon、版本血缘和人工审核记录。
