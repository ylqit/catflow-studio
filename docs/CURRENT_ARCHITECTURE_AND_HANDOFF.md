# CatFlow 当前架构与开发交接

更新：2026-09-14。本文描述当前代码；部署和样片完成情况分别记入本轮交付记录。接口事实以生成的 `packages/contracts/openapi.json`、代码和 Alembic 为准，当前迁移 head 为 `0035_character_references`。

## 运行结构

Vue 3 / TypeScript / Vite 是唯一正式前端。FastAPI 默认在 `127.0.0.1:8877` 同源提供 SPA、REST、SSE 和本地媒体。PostgreSQL 是唯一业务状态源，持久 Worker 执行 Ark 规划、图片、视频，以及本地 FFmpeg 处理。没有运行时 Fake Provider、Scene/ShotCard 旧工程或第二套工作流数据库。

浏览器保存视图和查询状态；作品、来源原文、Canon、系列、版本、任务、外部回执和剪辑记录保存在 PostgreSQL。媒体存储为受管相对路径及 SHA256。当前配置由本机 `.env` 决定，不能把文档中的历史数据库名直接当成仍存在的业务库。

## 三条生产路径

| 路径 | 输入与结果 | 边界 |
|---|---|---|
| 整片生成 | 已采用故事、环境、1–4 镜分镜 → 一条约 8–15 秒视频候选 | 全部镜头按累计时间编译，创建前预览并冻结 |
| 逐镜生成 | 当前镜头设计 → 起始图确认 → 单镜视频 → 本地组装 | 只编译当前镜头，时间从零开始；严格首帧仅约束开始状态 |
| 局部编辑 | 来源视频/剪辑草稿、选区、用户文字、实际参考 → 替换候选 → 本地试用与保存 | 选区外保持原样；双播放器展示真实修改前后来源；音轨策略随 EDL 保存 |

三条路径共用任务生命周期和参考来源，但不互相替代。局部编辑的现代契约可使用短选区，提供方候选仍受模型最短时长限制；旧 EDL 和早期编辑任务保留原解释规则。详见 [双播放器与逐镜生产](DUAL_PLAYER_SCENE_PRODUCTION.md)、[视频候选试用](VIDEO_CANDIDATE_TRIALS.md)。

## Canon、创建、导入与系列

`cat_reference_options` 只维护 `gray-original` / `white-v4` 选择目录。实际生产绑定始终是项目/系列的 `canon_profile_id`，主图、比例图和身份文字来自同一不可变 Canon。共享儿童与画风板，辅助正/背/三视图仅供查看。

新建短片、新建系列和导入目标使用同一选择器并显式提交选择。新页面默认灰猫，已有目标和单集继承所属系列。制作前允许在事务中切换；首次模型任务入队或已有结构化制作成果后锁定。换猫通过独立重制对象，继承原始输入、来源和参数，重新规划；不复制旧分镜、视频或连续性链。详见 [猫咪参考选择](CAT_REFERENCE_OPTIONS.md)。

基础整片视频参考按职责为儿童、所选猫咪主图、同套比例图、本集环境、固定画风板。上一集视频依照系列连续性决策选用；单元故事不自动把前集场景和道具带入。环境属于作品；固定 Canon 不包含动态环境。`style_source` 不进入 Provider 请求。

## 节拍与表演

新导演契约 `professional-director-v4-performance` 要求每镜 `actionBeats`。数据库继续保存既有分镜 JSON，不增加独立时间线表。节拍使用镜头内 24 fps 左闭右开帧区间，保存触发/行动/反应/回报、儿童动作、猫咪动作、可见变化及可选注意目标、眼睑动作与可见性。

节拍负责动作顺序；走位负责初始支撑、空间和结束位置。服务保存时从节拍派生旧动作摘要和 movementPath，清空旧 microMotions，页面不让两套动作并行编辑。旧分镜缺少节拍时继续读取原有动作，不自动补写；序列化省略空的新增字段，以保持历史设计哈希。

`application/creative_direction.py` 集中故事、系列、单集、导演和编辑各自适用的规则：眼型身份不锁定眼睑和目光；动作有因果，猫咪可以影响儿童的后续行动；自然收尾允许短暂停留。适度增写须由既有用户补充说明授权并冻结。独立故事输出 Schema 使用项目目标时长。

整片编译版本为 `seedance-professional-v9-performance`，逐镜为 `catflow-shot-production-v3-performance`，现代编辑为 `segment-edit-v8-performance`。旧任务按其冻结文本/版本继续执行，Worker 不读取当前全局默认重新编译。当前目录查看不会上传辅助视图。

## 冻结、并发与恢复

API 预览展示真实编译文本及参考职责，创建时核对输入哈希并以幂等键入队。冻结 Canon ID/哈希、身份、资产 ID/哈希、故事和分镜版本、提示词和输出 Schema。参考切换与入队共享所属项目/系列锁。修改节拍会改变设计/预览哈希，已确认镜头需重新确认。

Worker 持久保存外部 task ID、原始回执、下载和落盘状态。提交未知先查询/对账，不盲目重交；已有内容的格式问题可从原结果本地修复。旧导演 v2/v3、旧媒体提示词包装、旧 EDL 和历史任务分支有恢复职责，继续保留。详见 [外部任务状态与恢复](JOB_EXECUTION_RECOVERY.md)。
