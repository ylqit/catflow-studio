# 设计脚本教程到 CAT-VIDEO-GENERATOR 的适配说明

`docs/设计脚本教程` 是导入的原始课程资料，本项目不修改其正文和附件。系统只吸收其中与
当前二维儿童与猫咪生活短片一致的工作流思想，并通过下面的边界完成适配。

## 采用的分层方法

- 角色卡对应项目视觉档案 Revision，长期锁定齐下颌短发 8–9 岁儿童和固定灰白虎斑猫身份。
- 场景设定与道具设定对应场景视觉基准，只保存本场共同服装、配件、环境基调和共同道具。
- 片段关键首帧对应片段锚点，不把包含特定姿态、动作结果和构图的场景视觉基准无差别用于全部片段。
- 首尾帧衔接对应 `shot_tail_frame`：批准视频后用本地 FFmpeg 抽取稳定尾帧，下一片段可人工采用。

## 与教程不同的约束

教程中的镜头精确秒点只作为创作分析思想。系统不根据时长用关键词规则改写剧本；当用户
调整片段时长后，可逐次确认让 LLM 结合批准剧情、相邻片段和真实素材重新建议 2～4 个子镜头、
定性节奏和正文。最终正文不编造每个子镜头的精确秒点。

课程中的写实微表情库不直接套用到本项目。当前 Canon 是二维日系治愈画风，只保留“按景别
克制增加自然微动作”的原则；猫咪保持自然四足动作，人物承担开合、拿取、穿戴和工具操作。

## LLM 的职责

同一个 Ark 规划模型按四个角色串行工作：剧情医生只诊断原稿；剧本编辑根据人工接受的方案
重写完整剧情；分镜导演只拆分批准剧情；视觉与 Prompt 审稿实际查看当前、相邻片段和用户
勾选的压缩参考图，返回素材适配、锚点方式与 Seedance 创作正文候选。每次调用都由用户单独
确认，原始 `providerOutput` 永久保留。

用户上传的通用图片不会自动取得人物或猫咪的长期身份职责。Canon 人物、猫咪与画风职责由
来源锁定；通用素材先按 prop、composition 或 style 使用，再由视觉审稿 LLM 查看实际图片并
建议保留、移除或调整职责，最后仍由用户确认。

LLM 不直接覆盖人工稿，也不直接控制 Seedance。用户先编辑或勾选候选，系统用输入哈希和草稿
Revision 防止接受过期分析。最终 Prompt 由人工确认的 LLM 正文加系统技术外壳组成；外壳只维护
技术参数、长期视觉档案、真实图片顺序/职责和固定排除项，不承担剧情合理性判断。

代码中不硬编码某一剧情案例的容器、道具或动作规则。物理可行性、动作密度、空间关系和素材
是否适合作为动作起点均由对应 LLM 角色结合上下文分析，再由人工确认。

## 场景视觉基准与片段策略

- `off`：本片段不引用场景视觉基准。
- `appearance_only`：默认，只继承造型、环境基调和共同道具，忽略姿态、动作结果和构图。
- `full_reference`：片段起始状态与视觉基准高度一致时，完整参考姿态与构图，但仍不把它声明为首帧。
- `derive_anchor`：视觉基准只参与 Seedream 开场锚点生成；锚点批准后不再重复进入视频。

因此，场景视觉基准历史只表达共同视觉基线；片段不同状态通过策略、片段自定义参考或锚点解决，
不会为了某个片段创建伪装成场景基准的新版本。

## Toonflow 式生产工作台的适配边界

本项目借鉴的是“章节—独立视频片段—内部子镜头—转场—成片”的编排方式，而不是一次模型
调用生成 1～5 分钟视频。每个 8～15 秒片段仍独立提交 Seedance；失败、整段重做或子镜头区间
重拍只产生当前片段的新版本，不覆盖其他片段。批准片段最后由本地 FFmpeg 组装成长视频。

本轮不采信本地文章中尚未由当前 Ark 契约验证的 Seedance 2.5、50+ 素材或 4K 宣传参数，也
不接入视频参考、音频参考、智能拉片、镜头运动提取或 Blender 白模。这些能力不能通过在 Prompt
中写出不存在的 `@视频N`、`@音频N` 来模拟。

## 素材命名与 Auto Link

用户上传的项目图片可以命名为“伸缩鱼竿”“玄关高柜”等稳定名称。片段正文使用编辑器内部
标记 `{{人物}}`、`{{猫咪}}`、`{{场景}}`、`{{道具:伸缩鱼竿}}`，不手工维护序号。预览和提交时，
系统先判断 Provider 输入模式：有批准首帧锚点时只提交该锚点；没有锚点时，才按“片段自定义 →
场景视觉基准 → 项目 Canon”取真实可读普通参考图，并按资产 ID、内容 SHA 去重，再把标记编译为
`人物“小孩”@图片1` 等 Provider 指代。引用变化会整体重排；
未绑定标记、缺失文件、超过九张图片或不存在的 `@图片N` 都在付费提交前阻断。

## 生成连续性和后期转场

- 同场连续动作优先采用上一批准片段的稳定尾帧作为下一片段首帧锚点。
- 主动换机位时生成独立锚点，并在分镜正文中保持人物位置、动作方向和道具状态。
- 场景或时间变化时使用独立环境锚点，不强行沿用旧场景尾帧。
- 后期默认 `cut`；时间或地点跳转可用 `fade_black`；柔和时间流逝可用短
  `cross_dissolve`。叠化会重叠相邻片段并缩短成片总时长。

LLM 只建议转场类型和下一片段起始状态，用户在成片编排器中确认。后期转场不触发 Ark 调用。

## 子镜头与区间重拍

片段内部的 2～4 个编号子镜头仍属于一次 Seedance 生成。时间线把视频诊断边界按顺序映射到
子镜头；边界不足时提供等比例估算并明确标记，用户可手工修正起止时间。点击“重拍子镜头 N”
只会预填该子镜头文字与区间，实际区间替换继续保留原视频前后上下文和所有历史版本。
