# Canon-v4：原创一人一猫统一身份与纯画风板

Canon-v4 继续复用 Canon-v1 已批准的儿童和猫咪身份图片，但不再把绿色叶片照片作为普通生成参考。叶片照片仅保留为 `style_source:leaf_material_v1` 血缘证据，`providerEligible=false`。

`style:healing_line_texture_v4` 是从叶片照片的材质、柔光和空间层次，以及现有角色插画的轮廓线与色阶中蒸馏出的纯画风板。它不包含人物、猫咪、植物、文字或绿色主导构图，是后续角色设计、环境和视频生成唯一可提交 Provider 的画风资产。

儿童身份的正式运行解释已统一为 6–7 岁、约 1.2 米、约 4.5–5 头身，保持柔和圆润脸型、深棕黑色齐下颌短发和低龄儿童身体结构；服装、表情与姿态属于本集可变项。猫咪身份固定为同一只灰白虎斑猫，保持头脸、金棕色眼睛、粉色鼻口、毛色分区、主要虎斑、四足结构和尾巴环纹。

本目录仍是历史设计源。正式运行只读取 `assets/canon/v4` 生产包及其 manifest。

叶片、绿色、露珠和微距摄影只属于画风提炼阶段的 `sourceExclusions`，不是普通故事或环境生成的全局禁令。
