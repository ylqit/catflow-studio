# Canon v1 视觉定稿

本目录以 `../人与猫咪.png` 为共同身份与画风母版，生成并审核后形成新的生产参考集。

## 人物

- 身份：同一个偏中性呈现的东亚儿童，约五至七岁。
- 发型：深棕黑色齐耳至下颌短波波头、轻薄刘海；不使用马尾或发髻。
- 基础服装：米白短袖、藏青中裤、棕色草编凉鞋。基础服装只用于Canon识别，实际剧情允许合理换装。
- `人物三视图.png`只用于审计和确定性裁分，不直接传给生成模型。
- 生产使用：`人物-大头照.png`、`人物-全身.png`、`人物-正面.png`、`人物-侧面.png`、`人物-背面.png`。

## 猫咪

- 同一只圆润灰白短毛猫。
- 白色口鼻、胸腹与四肢，灰色头顶和背部虎斑；尾巴为灰白环纹、自然中等粗细，从后躯正常连接并向末端收细；圆形琥珀棕眼睛。
- `猫咪三视图.png`只用于审计和确定性裁分。
- 生产使用：`猫咪-正面.png`、`猫咪-侧面.png`、`猫咪-背面.png`。

## 画风

- 日系二维治愈生活插画。
- 细腻手绘轮廓、柔和哑光水彩质感、清新自然色、温和自然光和克制景深。
- 排除真人写实、CG/PBR、塑料高光、强烈三维体积塑形和高反差商业动画灯光。
- `画风-线条材质.png`负责近景线条、叶片材质与水滴细节。
- `画风-户外.png`负责户外色彩、空气透视与自然光。
- `画风-室内.png`负责室内木材、布料、墙面和柔和窗光。

原始 `人与猫咪.png` 含水印且人物发型与部分定稿视频不一致，因此不直接作为运行时Canon。新Run只选择本目录裁分后、已批准且语义键精确匹配的最新资产。

`主题示例`、`画风示例` 和数据库中的旧 Canon 已退出生产链。以后导入同一语义键的新版本时，系统会在同一事务中自动退役旧版本；历史任务仍可按资产 ID 审计，但不会再次选中旧图。

`docs/采茶叶.mp4` 只用于确认二维日系治愈、水彩材质、茶园自然光与克制景深；样片中的马尾人物不属于角色身份 Canon，也不得覆盖本目录的短波波头人物设定。人物换装时继续锁定脸型、五官、短发、年龄感和头身比例；猫咪换场景时继续锁定灰白分区、虎斑、眼睛、尾巴与体型。
