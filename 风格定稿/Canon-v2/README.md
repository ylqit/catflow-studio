# Canon-v2：一人一猫治愈短片

Canon-v2 是配方使用的语义选择档案，不复制 Canon-v1 已批准的二进制资产。
运行时根据 `assetSourceManifest` 中的 semantic key 解析同一组人物与猫咪身份图。

- 固定人物：`person:headshot`、`person:fullbody`
- 固定猫咪：`cat:front`、`cat:side`
- 室内画风：仅使用 `style:indoor`
- 户外画风：仅使用 `style:outdoor`

准写实露珠叶片 `style:line_texture` 不属于本档案，不能进入治愈短片配方的默认参考包。
该文件不是 Canon 修复清单；Canon 修复仍使用 Canon-v1 的不可变哈希清单。
