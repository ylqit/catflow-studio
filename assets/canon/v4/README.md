# CatFlow Canon v4 生产包

本目录是 CatFlow Studio 唯一正式 Canon 源包。`风格定稿/` 继续作为设计历史和审计来源，不直接进入运行时 Provider 请求。

儿童身份固定为同一位 6–7 岁、约 1.2 米高的短发儿童：深棕黑色齐下颌短发、轻薄刘海、柔和圆润的低龄儿童脸型，以及约 4.5–5 头身的儿童插画比例。猫咪身份固定为同一只灰白虎斑猫，保持灰白毛色分区、主要虎斑、金棕色眼睛、粉色鼻口、环纹尾巴和正常四足结构。

四个文件各自只有一个职责：

- `episode-child.png`：儿童身份。
- `episode-cat.png`：猫咪身份。
- `pair-scale.png`：一人一猫的相对尺寸、同地面站位和透视。
- `style-board.png`：线条、材质、色彩和光感。

Provider 只允许使用 `manifest.json` 中 `assets` 列出的四个文件。人物/猫咪三视图、大头照、背面图、叶片材质来源、户外茶园画风、带“即梦AI”水印的人猫图，以及所有 `style_source` 都不能进入正式图片或视频请求。

比例板由 Codex imagegen 基于 `人物-全身.png` 与 `猫咪-侧面.png` 生成。生成要求为单一儿童、单一猫咪、自然站立、同一水平地面、猫咪头顶约到儿童膝部、中性暖灰背景，无植物、道具、文字、Logo 或水印；该生成不属于 Ark 首批 9 次付费调用。
