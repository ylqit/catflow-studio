# 白猫参考图预览包 v1

> 状态：已发现角色外形偏移，停止用作后续猫咪身份参考。站姿体型、胸腹毛量、灰纹分布和尾巴形态偏离指定精修稿。保留本目录作为历史对照；修订候选与分析见 ../white-cat-v2/README.md。

本套图片使用内置 imagegen，以本目录的 identity-seated.png 精修坐姿图为猫咪身份基准制作。它们用于角色设计与适配预览，尚未接入正式 Canon 生产包。

## 图片用途

- identity-seated.png：上一轮完成的精修坐姿身份图，保留圆脸、大眼、粉鼻、白底浅灰虎斑和蓬松胸毛。
- front-standing.png：正面四足站姿，核对脸型、眼睛、胸毛和前肢。
- side-standing.png：朝左的侧面站姿，核对口鼻侧轮廓、躯干长度、腿部结构与尾巴。
- rear-standing.png：背面站姿，补充后脑、背部花纹、后肢与尾根设计。
- three-view-board.png：正面、侧面、背面横向对照板，供人工核对角色设计。
- pair-scale.png：同一位既有儿童与新白猫的同框比例参考，儿童站左侧，猫咪站右侧，同地面站位。
- generation-prompts.md：本轮各张图片实际使用的完整提示词与输入图职责。

## 角色与风格基准

猫咪保留圆脸、大而深色的眼睛、短口鼻、粉鼻与粉色耳内、白色胸腹和脚爪、浅灰虎斑以及蓬松环纹尾巴。画法采用柔和数字插画、暖灰细轮廓、完整浅灰色块、柔和明暗和轻微纸感。

站姿侧面和背面包含对原坐姿图中不可见结构与毛纹的设计补充，属于本轮提出的连续设计；原图本身不能证明这些隐藏部位的精确花纹。各视角是生成式绘制，不能当作经过几何校准的三维建模正投影图。

人猫比例沿用现有约 1.2 米儿童的设定，目标为猫咪头部最高处大致到儿童膝部。比例图用于视觉比例参考，不是精密尺寸测量。

## 使用边界与检查

所有图片均为预览资料，不会因存入本目录而自动进入视频请求。本次没有替换 assets/canon/v4 中的正式猫咪、人猫比例图、manifest 或角色提示词。

三视图板不应直接作为正式视频中的单猫身份图提交；板上有三个角色视角，可能被理解成多只猫。后续正式接入应选择经过确认的独立猫咪图与人猫比例图，并同步正式素材清单和身份描述。

本轮进行静态检查与 PNG 解码检查。真实视频中的转头、行走、遮挡恢复、花纹稳定性和人猫互动尚未实测。正式采用前应使用相同角色参考完成这些镜头验证。
