## 看不见的背部为何仍要补全

后续转身、背向行走或绕拍需要统一的背部设计。若只留下“白底浅灰虎斑”这个宽泛描述，每次生成仍可能发明不同的背纹。补全需要兼顾原图衔接与背面本身的完整性。

本轮采用以下设计：
- 后脑和颈背以白毛为主，耳背延续边缘可见的柔和灰色；不把额头 M 纹搬到后脑。
- 肩背由两侧原有斜向灰纹向中间收束，采用不等长、不等宽的断续斑纹和毛束边缘。
- 背中有少量灰纹进入，不留下笔直的空白条带，也不画整片灰色背鞍或贯通脊柱的深灰线。
- 灰斑作轻微不对称分布，以不同大小的白色间隔取得视觉平衡；避免左右镜像的点阵和等距横环。
- 臀部斑纹向尾根自然过渡，尾巴保持落地卷曲；花纹浓淡与原稿的暖中性灰接近。

这些是新提出的隐藏区域设计，不能声称是从原图精确恢复的“真实背纹”。一旦后续确认，应把该背面作为同一角色的固定资料，避免每个镜头重新设计。
